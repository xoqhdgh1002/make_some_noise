# ✨ 마법 크롭 (Magic Crop)

> AI 기술로 아무리 어려운 전공 서적이나 논문이라도, 모르는 부분만 콕 찍어 '크롭'하면 마법처럼 쉬운 말로 번역해 주는 혁신적인 온라인 지식 플랫폼

[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.0-38bdf8)](https://tailwindcss.com/)

## 📖 프로젝트 소개

**마법 크롭**은 전공 지식과 일상 언어 사이의 거대한 장벽을 허무는 AI 기반 학습 플랫폼입니다.

### 🎯 핵심 가치

- **지식 접근의 평등**: 비전공자도 전문 지식에 쉽게 접근
- **맞춤형 학습**: 난이도를 조절하여 자신의 수준에 맞는 설명 제공
- **직관적 이해**: 실생활 비유와 시각화로 복잡한 개념을 쉽게 이해

### 👥 타겟 사용자

- **핵심 타겟**: 새로운 분야의 지식을 얻고 싶지만, 전문 용어와 복잡한 이론에 막막함을 느끼는 비전공자 및 일반 대중
- **확장 타겟**: 자신의 전공을 더 쉽게 복습하거나, 타 분야 지식을 빠르게 흡수하고 싶은 대학생/대학원생 및 연구자

## ✨ 주요 기능

### 1. 📖 PDF 뷰어
- 전공 서적이나 논문을 웹에서 바로 읽을 수 있는 뷰어
- 페이지 네비게이션 및 확대/축소 기능

### 2. ✂️ 마법 크롭 (핵심 기능)
- 마우스 드래그로 이해하기 어려운 부분을 선택
- AI가 즉시 선택된 내용을 분석하고 쉽게 설명

### 3. 🎚️ 난이도 조절 슬라이더
- **순한맛** (😊): 초등학생도 이해할 수 있는 수준
- **중간맛** (🤔): 일상 예시를 포함한 중학생 수준
- **매운맛** (🔥): 전문 용어를 포함한 고등학생 이상 수준

### 4. 💡 찰떡 비유 & 시각화
- 어려운 개념을 실생활 비유로 설명
- 복잡한 데이터를 간단한 인포그래픽으로 시각화 (예정)

## 🚀 시작하기

### 필수 요구사항

- Node.js 18.0 이상
- npm 또는 yarn

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

### 환경 변수 설정 (선택사항)

AI 기능을 사용하려면 `.env.local` 파일을 생성하고 다음을 추가하세요:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

> **참고**: API 키가 없어도 더미 데이터로 기능을 테스트할 수 있습니다.

## 🛠️ 기술 스택

### 프론트엔드
- **Next.js 14**: React 기반 풀스택 프레임워크
- **TypeScript**: 타입 안정성
- **Tailwind CSS**: 유틸리티 기반 CSS 프레임워크
- **react-pdf**: PDF 렌더링
- **Zustand**: 가볍고 빠른 상태 관리

### AI & API
- **Vercel AI SDK**: AI 통합을 위한 SDK
- **OpenAI API**: GPT 모델을 통한 설명 생성

### 개발 도구
- **ESLint**: 코드 품질 관리
- **Lucide React**: 아이콘 라이브러리

## 🎮 사용 방법

1. **PDF 업로드**: "PDF 파일 업로드하기" 버튼을 클릭하여 전공 서적이나 논문 PDF를 선택합니다.

2. **난이도 선택**: 원하는 설명 난이도를 선택합니다 (순한맛/중간맛/매운맛).

3. **크롭하기**: PDF에서 이해하기 어려운 부분을 마우스로 드래그하여 선택합니다.

4. **설명 확인**: AI가 생성한 쉬운 설명, 찰떡 비유, 시각화를 오른쪽 패널에서 확인합니다.
